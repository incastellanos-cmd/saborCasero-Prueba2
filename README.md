# saborCasero-eva2

## Pruebas

Las pruebas unitarias se ejecutan con Vitest:

```bash
npm test
```

La suite cubre las operaciones CRUD de productos, el filtrado y los precios promocionales, la validación del checkout y el renderizado de la vista de ofertas.

## Flujos de demostración

El registro, el formulario de contacto y el checkout funcionan localmente. El pago permite simular un resultado aprobado o rechazado; no procesa pagos reales ni envía datos a un backend.
